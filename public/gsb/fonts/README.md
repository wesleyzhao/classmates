# Classmates fonts

Locally served WOFF2 files avoid third-party font requests during play. Preserve these notices when redistributing the fonts:

- `press-start-2p-latin.woff2`: Press Start 2P, SIL OFL 1.1. [Upstream notice](https://github.com/google/fonts/blob/main/ofl/pressstart2p/OFL.txt), copied as `LICENSE-pressstart2p.txt`.
- `vt323-latin.woff2`, `vt323-latin-ext.woff2`: VT323, SIL OFL 1.1. [Upstream notice](https://github.com/google/fonts/blob/main/ofl/vt323/OFL.txt), copied as `LICENSE-vt323.txt`.
